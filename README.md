# Justgiviner

A website offering sarcastic wisdom and weekly insights.

## Features

- **Homepage** with email newsletter signup (bi-weekly AI-generated content)
- **"Questions for the Almighty"** - Interactive search bar that provides sarcastic/sparky answers
- **News Page** - Weekly updated articles (designed to be updated by Copilot)
- **Videos Page** - Showcase of YouTube content
- **Patreon Page** - Support tiers and patron benefits

## Getting Started

Simply open `index.html` in a web browser, or serve the files using any web server:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.

## Structure

- `index.html` - Homepage with newsletter signup and question feature
- `news.html` - News articles page
- `videos.html` - YouTube videos showcase
- `patreon.html` - Patreon support page
- `styles/main.css` - All styling
- `scripts/main.js` - Interactive functionality

## Technologies

- Pure HTML5, CSS3, and vanilla JavaScript
- No frameworks or dependencies
- Fully responsive design
- Client-side form validation and interactions
